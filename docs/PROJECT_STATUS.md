# B2B Parser — статус проекта

Актуально на 29 октября 2026 года.

## Готово (код)

- Форк horeca_parser 89ced6b; ядро без изменения логики.
- 20 сегментов в `config/segments.py`; OSM, VK, Яндекс и crawler читают
  таксономию только оттуда. Матрица Яндекса — 39 городов × 60 запросов.
- Исключения: сети, госорганы, HoReCa/отели (флаги `excluded_*`),
  пересечение с другими базами через `EXCLUDE_MASTERS`. По итогам аудита
  24.09 фильтр госорганов покрывает школы/поликлиники/аббревиатуры
  (МБУ ДО и т. п.), `EXCLUDE_BRANDS` расширен (Gloria Jeans, Аско и др.).
- Сигналы «повода для КП» с кэшем `output/web_signals.json`.
- `outreach_ready.xlsx` с колонками Сегмент/Все сегменты/Повод для КП/Сигналы;
  `approved_for_send=false` всегда.
- Enrichment (01–03.10): статический HTTP-проход перед браузером,
  email-first, память между прогонами (`output/enrich_cache.json`),
  параллельные страницы Chromium, таймаут на сайт, шлюз качества email
  (ROT13, `%20`, платформенные/спам/опечатки), зеркала Overpass.
- VK (08.10, ветка `fix/vk-error-handling`, влита 29.10): ошибки API
  выводятся и при сбое всех запросов источник падает, а не пишет «ok, 0 групп».
- `CHROMIUM_SANDBOX=0` (29.10) — выключение песочницы Chromium только для
  локального запуска на Windows; на Linux песочница включена всегда.

## Приёмка

24.09.2026, локально:

- Полный OSM: 3 416 наблюдений → 3 266 компаний, все 20 сегментов
  заполнены; 380 с email; исключено: госорганы 40, сети 35, HoReCa/отели 7.
- OSM + enrichment (30 сайтов) + сигналы: exit 0, `outreach_ready` — 279.
- Canary Яндекса (Симферополь, 2 шаблона): 10/10 карточек, CAPTCHA нет.
- Ручной аудит 50 строк outreach: 90–94% — верные крымские компании.

29.10.2026, Windows-машина разработчика (Python 3.12, `requirements.lock`):

- `pytest`: 393 passed.
- `DRY_RUN=1 ONLY_SOURCE=osm`: exit 0, 25 записей, все artifacts и handoff.
- Canary Яндекса: Chromium с песочницей на этой машине падает
  (`TargetClosedError`). С `CHROMIUM_SANDBOX=0` (Симферополь, «строительная
  компания»): 10/10 карточек, 9 с телефоном, CAPTCHA нет, exit 0.
- Исправлено: у карточки без номера в поле телефона оказывалась подпись
  «Телефон»; теперь значения без цифр отбрасываются, срабатывает fallback
  по тексту страницы, а карточка без номера получает статус `empty`.

Наблюдение: в OSM встречаются записи без названия, где имя = категория
(«Парк» из `amenity=bicycle_rental`, «Касса», «Шиномонтаж», город «Крым»).
В outreach они не попадают (нет email), но засоряют master.
